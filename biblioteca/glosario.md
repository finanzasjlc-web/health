# Glosario

| Término | Definición |
|---|---|
| 1RM | Carga máxima que se puede levantar una sola vez con técnica correcta |
| ACWR | Ratio carga aguda (7 días) / carga crónica (28 días) |
| CMJ | Counter Movement Jump, salto vertical con contramovimiento |
| FC | Frecuencia cardíaca |
| FTP | Functional Threshold Power: potencia máxima sostenible ~1 h en ciclismo |
| GET | Gasto energético total diario |
| HRV | Variabilidad de la frecuencia cardíaca, indicador de recuperación |
| Macrociclo | Periodo largo de planificación (meses), orientado a un objetivo principal |
| Mesociclo | Bloque de 3-6 semanas con un énfasis concreto |
| Microciclo | Normalmente una semana de entrenamiento |
| NEAT | Gasto energético por actividad no deportiva (andar, trabajar, etc.) |
| RIR | Repeticiones en reserva: cuántas reps quedaban antes del fallo |
| RPE | Rate of Perceived Exertion: esfuerzo percibido, escala 1-10 |
| sRPE | Carga de sesión = duración × RPE |
| Tapering | Reducción progresiva de la carga antes de una competición |
| TMB | Tasa metabólica basal |
| VO2max | Consumo máximo de oxígeno |
| VT1 / VT2 | Umbrales ventilatorios 1 (aeróbico) y 2 (anaeróbico) |
