# Documentación inicial aportada por el deportista

Guarda aquí todo lo que tengas. Cuanto más completo, mejor será el plan. Nombra los archivos así: `AAAA-MM-DD_tipo_descripcion.ext` (ej. `2026-11-10_analitica_sangre.pdf`).

## Checklist de documentos

### Salud (prioridad alta)
- [ ] Analítica de sangre reciente (< 6 meses). Ideal que incluya: hemograma, ferritina, hierro, transferrina, vitamina D, B12, folato, glucosa, HbA1c, perfil lipídico, creatinina, urea, transaminasas, TSH, T4, cortisol, testosterona (si procede), CK, PCR, magnesio, zinc.
- [ ] Reconocimiento médico deportivo / electrocardiograma.
- [ ] Prueba de esfuerzo (si existe): VO2max, umbrales, FC máx.
- [ ] Informes de lesiones, cirugías o fisioterapia.
- [ ] Lista de medicación y suplementos actuales (nombre, dosis, desde cuándo).
- [ ] Alergias e intolerancias documentadas.

### Composición corporal
- [ ] Mediciones previas (bioimpedancia, DEXA, pliegues) con fecha.
- [ ] Fotos de referencia: frente, perfil, espalda. Misma luz, misma hora, misma ropa. Fecha visible.

### Historial deportivo
- [ ] Planes de entrenamiento anteriores.
- [ ] Marcas / resultados de competiciones.
- [ ] Exportación de datos de dispositivos (Garmin, Polar, Strava, Apple Health, Google Fit…) de los últimos 3-6 meses.

### Nutrición
- [ ] Registro de alimentación de 3-7 días (incluyendo un fin de semana), con horas y cantidades aproximadas.
- [ ] Planes nutricionales previos.

### Contexto
- [ ] Horario semanal típico (trabajo, estudios, familia, desplazamientos).
- [ ] Material y lugar de entrenamiento disponible (gimnasio, casa, pista…), con fotos si ayuda.
